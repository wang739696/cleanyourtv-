CleanYourTV 管理器是一个运行在安卓手机上的 App，通过局域网里的 ADB 连接你的安卓电视或盒子，在手机上完成原本要拿遥控器、插 U 盘或接电脑才能做的事。

不需要 root，也不需要把手机连电脑。
手机和电视在同一个局域网，电视打开网络调试（ADB）即可。
首次连接时电视会弹出调试授权，点允许后以后不再询问。

一、连接电视
手动连接：填电视的 IP 地址，点“连接电视”。输入框回车也可以直接连接。
扫描局域网：不知道电视 IP 时，点“扫描局域网”。App 会找出开放了 ADB 端口的设备，列出设备名和 IP，点一下就自动填入。
设备信息：连接成功后，页面会显示电视的品牌、型号、系统版本和当前的桌面模式。

二、实时电视画面与截屏
连接成功后，主页上方的预览框会显示电视当前的真实画面，每 10 秒刷新一次。

后台预览：预览可以由一个前台服务在后台维持，通知栏会有提示。没给通知权限时，退回到“页面打开期间刷新”的方式，功能不受影响。
截屏并保存：点“截屏并保存”，会截下电视当前的画面，先弹出预览，可以分享，也会存到手机相册。Android 9 及以下需要授予存储权限。
三、桌面管理
这是管理器最核心的部分，用来换掉电视上被广告和推荐位塞满的原厂桌面。

图片


安装 CleanYourTV 桌面：把内置的 CleanYourTV 桌面装到电视上，设为默认桌面，并自动开启它的“桌面守护”，防止电视重启或待机唤醒后被原厂桌面抢回去。原厂桌面保持启用，不会被卸载。
安装 Aerial TV 桌面：同样的方式安装另一套桌面 Aerial TV，并为它授予运行所需的权限。
切换到 CleanYourTV / 切换到 Aerial：两套桌面都装好后，可以随时在它们之间切换，不用重新安装。切换时会让另一套桌面的守护让路，避免按 Home 键时两边互相抢。
恢复原始桌面：一键切回电视原厂桌面，不卸载 CleanYourTV。安装桌面前，管理器会先核验并保存原桌面的信息，恢复时用。
兼容不同电视：管理器会识别电视类型，对小米这类特殊系统使用“小米兼容模式”，对老版本系统使用对应的桌面安装包。
每一步都核验：安装和切换完成后，会读回电视的真实状态，包括当前默认 HOME、两套桌面守护是否开启，结果直接显示出来，而不是只告诉你“命令执行了”。
每个桌面操作执行前都会弹出确认框，说明将要做什么。

四、电视应用管理
点“查看应用”进入应用管理页，管理电视上安装的所有应用。

图片
扫描与核验：列出电视上所有应用，显示名称、图标和包名，并标出哪些可以操作、哪些因为是系统关键组件被保护。
搜索：按名称或包名搜索。
启用 / 停用：可以单个或多选批量启用、停用应用。停用不是卸载，也不清理数据，随时可以重新启用。操作前会保存状态快照，并重新核验保护条件。
一键优化：根据电视机型匹配一份内置的清单，把确认可以停用的预装应用列出来，你确认后再批量停用。匹配不到唯一机型时不会执行任何操作。
打开应用：直接在手机上点，就能在电视上启动该应用。
主页应用网格：主页还有一个电视应用的快速入口，点图标即可在电视上打开。
五、电视文件管理
在手机上浏览和管理电视的存储。

图片


浏览目录，点路径栏可以直接输入路径跳转，也可以回到上一级。
上传文件、上传文件夹：从手机传到电视，带进度条，可以随时取消；遇到同名文件会先询问怎么处理。
下载到手机：把电视上的文件保存到手机，失败时会尽量清理没传完的文件。
新建文件夹、重命名、删除、复制路径：删除不可恢复，所以会有二次确认。
直接安装 APK：在电视里选中 APK 文件，可以在电视上直接安装，失败时给出原因和建议。
安全限制：只有用户存储和临时目录允许修改，其他目录只读浏览，避免误操作系统文件。
六、遥控器
手机变成电视遥控器，不依赖红外，也不需要另外配对。

方向键、确认、返回、主页、菜单、信号源、设置、电源。
音量加减、静音、频道加减、播放/暂停。
方向键、音量和频道键支持长按。
优先使用低延迟的连接方式，按键响应更快；连接断开时会自动重连，也可以手动点“重连”。

快速上手
在电视的开发者选项里打开“网络调试”或“ADB 调试”，记下电视的 IP 地址。
手机和电视连同一个 Wi-Fi，打开管理器，点“扫描局域网”，选中你的电视，点“连接电视”。
电视上弹出调试授权，点“允许”。
连接成功后，先点“只读桌面诊断”看一眼电视的情况，再决定安装哪套桌面。
随时可以在“恢复原始桌面”里退回原厂状态，所以放心试。
常见问题
扫描不到电视：确认手机和电视在同一个局域网，电视已打开网络调试，并且没有开启路由器的客户端隔离。
提示未授权：在电视上重新点允许，或者在电视的开发者选项里撤销所有调试授权后重连。
桌面装好了但按 Home 又回到原厂桌面：部分电视系统会在待机后抢回桌面，需要在电视的无障碍设置里允许桌面守护服务，可以先用“只读桌面诊断”看服务有没有开启。
